# Research visual agent orchestration canvases

## Purpose

Collect primary source URLs for the visual orchestration canvas research. The collector performs discovery only. The main researcher opens sources, adjudicates claims, and writes the finding.

## Scope

- Identify the intended Maestri project or record ambiguity.
- Locate official Orca documentation or source for visual and orchestration surfaces.
- Locate primary repositories or documentation for open-source canvas precedents.

No product or harness code changes belong to this package.
